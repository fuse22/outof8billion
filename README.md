# Один из 8 миллиардов — Telegram-бот

Симулятор жизни: ты рождаешься сегодня в случайной точке мира с реальной вероятностью
(по числу рождений в стране, данные Всемирного банка), проживаешь жизнь и делаешь выбор.

## Файлы
- `bot.py` — Telegram-часть (aiogram 3)
- `game.py` — игровая логика
- `countries.json` — 228 стран и общин
- `events.json` — жизненные события

## Запуск
Нужна одна переменная окружения: `BOT_TOKEN` — токен от @BotFather.
Команда запуска: `python bot.py`. Порт и вебхук не нужны (long polling).
Есть `Dockerfile` — подходит любой хостинг с Docker или Python.

Локально: `pip install -r requirements.txt` → `BOT_TOKEN=... python bot.py`
